Calculadora de Gorjeta (Tip Calculator)
Uma calculadora de gorjeta moderna e interativa desenvolvida com foco em design criativo (estilo recibo de compra) e ótima experiência do usuário (UX).

Status: Concluído | Tecnologias: HTML5, CSS3, JavaScript

Funcionalidades:

Design Exclusivo: Interface inspirada em um recibo de papel real, utilizando clip-path para bordas serrilhadas e efeitos visuais detalhados.
Carimbo Dinâmico: Um carimbo interativo que muda de frase e intensidade de acordo com a generosidade da porcentagem escolhida.
Cálculo em Tempo Real: Atualização automática dos valores (subtotal, gorjeta, total e divisão por pessoa) conforme o usuário digita ou interage com os botões.
Controle de Pessoas: Permite dividir a conta facilmente entre vários clientes.
Foratação Monetária: Suporte nativo ao padrão de moeda brasileira (BRL / pt-BR).
Responsividade: Layout adaptado para diferentes tamanhos de tela.

Tecnologias Utilizadas:

HTML5 (Marcação semântica e acessibilidade com aria-labels)
CSS3 (Variáveis CSS, Flexbox, Gradients e recortes com clip-path)
JavaScript Vanilla (ES6+) (Manipulação do DOM, formatação de dados e lógica interativa)
Google Fonts (Archivo e Space Mono).
